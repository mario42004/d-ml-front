## Estado funcional de la plataforma

### Productos actuales

1. `Audioprint`
   - Subida de audio.
   - Procesamiento por API.
   - Métricas, artefactos, historial y descarga de features.
   - Consume 1 coin por procesamiento.
   - Reembolsa la coin si falla por error de API/sistema.

2. `Audiometer`
   - Screening auditivo orientativo con Web Audio.
   - Historial de screenings.
   - Reporte con tabla y gráfica.
   - Frecuencia máxima: 12000 Hz.
   - Consume 1 coin al guardar screening.
   - Iniciar prueba y guardar están bloqueados si no hay coins.

### Seguridad y multi-organización

- Un usuario pertenece a una única organización.
- La organización inicial es `Genérica`.
- Superadmin puede crear/editar/eliminar organizaciones.
- No se puede eliminar `Genérica`.
- Si se elimina una organización:
  - Sus usuarios pasan a `Genérica`.
  - Sus roles de producto bajan a `user`.
- Superadmin puede cambiar la organización de cualquier usuario.
- Admins son de contexto/producto, no globales.
- Solo superadmin puede crear otros superadmins desde formulario exclusivo.
- El borrado de un superadmin exige escribir `ELIMINAR SUPERADMIN`.
- No se puede borrar el último superadmin activo.

### Borrado de usuarios

Al borrar un usuario:

- Se elimina la cuenta.
- Se eliminan datos asociados.
- Se eliminan audios.
- Se eliminan reportes.
- Se eliminan artefactos y archivos asociados dentro del proyecto.

### Coins / billing base

Se implementó sistema base de coins:

- `product_coin_wallets`: saldo por usuario-producto.
- `product_coin_ledger`: movimientos auditables.
- Usuarios nuevos reciben 5 coins por cada producto activo.
- Usuarios existentes en producción ya recibieron wallets iniciales.
- Superadmin puede agregar coins por usuario y producto.
- Preparado para futura compra de coins.

Producción quedó migrada:

- `wallets=9`
- `ledger=9`
- `users_without_wallets=0`
